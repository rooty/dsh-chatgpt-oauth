# Локальный ChatGPT OAuth для DeepSeek Harness

[English](README.md) | [Русский](README.ru.md) | [Українська](README.uk.md)

Минимальный плагин под контролем пользователя для **DSH 0.2.2-rc.1** (версия плагина **0.1.1**). Добавляет карточку входа в ChatGPT внизу страницы **Settings → Models** и вызывает установленный механизм авторизации `llm-pi-ai/openai-codex`. Плагин не реализует собственный протокол OAuth, не запускает Codex CLI, не заменяет провайдер DSH и не настраивает поиск или генерацию изображений.

## Использование

1. Откройте Settings → Models и найдите карточку **ChatGPT / Codex sign-in**.
2. Нажмите **Sign in with ChatGPT** / **Войти через ChatGPT**.
3. Выберите **Browser login (default)** и нажмите **Continue**, затем завершите вход на открывшейся странице OpenAI. Если браузер не открылся, воспользуйтесь ссылкой **Open ChatGPT sign-in** в карточке. Встроенный механизм также предлагает **Device code login (headless)**; при выборе этого способа следуйте инструкциям на экране.
4. Если DSH запросит код подтверждения или URL перенаправления, введите его только в карточке, а не в чате.
5. Когда DSH сообщит о сохранении данных входа, при необходимости настройте расположенный выше провайдер `openai-codex`. Загрузите список доступных моделей и нажмите Apply. Плагин намеренно сохраняет существующие списки моделей, адреса API и переопределения настроек провайдера.

Индикатор сохранённых данных означает лишь наличие записи в хранилище учётных данных DSH. Он не подтверждает права по подписке, действительность токена, доступность сервиса или успешное выполнение запроса к модели. Фактический вход и доступ к моделям нужно проверять интерактивно вместе с владельцем аккаунта.

Действие **Sign out of DSH** после подтверждения удаляет только запись `llm-pi-ai/openai-codex` из хранилища DSH. Оно не отзывает сеанс аккаунта в OpenAI, не выполняет выход из ChatGPT и не изменяет учётные данные Codex CLI.

## Безопасность и жизненный цикл

- Точные POST-маршруты регистрируются через существующий транспорт Connection `/api` в DSH, допускающий аутентифицированные подключения владельца (owner Peers). Плагин не запускает дополнительный API-сервер; встроенный браузерный OAuth может временно открыть локальный обработчик обратного вызова на порту 1455.
- Каждый маршрут дополнительно требует JSON Content-Type и заголовок `X-DSH-Codex-OAuth: 1`. Заголовок Origin веб-запроса, если он присутствует, должен соответствовать фактическому Host, включая порт. Аутентифицированный мост Desktop `dsh-app://app` намеренно удаляет Origin, поэтому отсутствие Origin допускается только внутри существующего транспорта Connection с аутентификацией владельца. Тело запроса ограничено 16 КиБ и проходит проверку.
- Одновременно может выполняться только одна попытка входа. Её случайный идентификатор хранится в инициировавшей вход карточке и не публикуется в общем состоянии; другие страницы получают только логический признак выполняющейся попытки.
- Запросы ввода, ссылки и коды подтверждения хранятся лишь временно. Встроенный механизм DSH записывает и обновляет токены в собственном хранилище учётных данных; плагин не читает и не возвращает их значения.
- Карточка содержит ссылки только на ограниченный набор официальных HTTPS-хостов OpenAI. Она не записывает ответы при входе в журналы и не сохраняет их в постоянном хранилище браузера.
- Отмена и размонтирование компонента прекращают попытку. Попытка истекает через десять минут, её конечное состояние — через одну минуту. Освобождение серверной части плагина отменяет работу и очищает таймеры.
- Плагин поставляется с готовым браузерным JavaScript, совместимым с загрузчиком. После установки обновите существующий интерфейс; наблюдатель разработки или отдельный веб-сервер не нужны.

## Проверка

Запустите `npm run check` из этого каталога с Node.js 22 или новее. Все 32 детерминированных теста используют синтетические учётные данные и имитацию встроенной авторизации; они не обращаются к OpenAI и не расходуют квоту. Клиентские тесты используют изолированные тестовые реализации хуков, а не настоящий браузер или DOM.

На macOS запустите `npm run test:native`: команда использует среду Electron, поставляемую с Desktop. Проверяются **реально установленные** AuthorizationService, адаптер pi-ai и транспорт Connection. Тест авторизации отменяет вход на этапе выбора браузерного входа или кода устройства **без ответа на запрос выбора**: браузер, обработчик обратного вызова, запрос кода устройства и обмен токенами не запускаются. Тест Connection проверяет допуск владельца для запросов формата Desktop и веб-запросов с совпадающим Origin, а также отклонение враждебных Host/Origin, анонимных запросов и запросов не от владельца. Аутентификация синтетическая, сокеты не создаются. Сетевой fetch отключён в обоих тестах. Настоящее хранилище учётных данных не создаётся и не проверяется.

Для версии 0.1.1 встроенные контракты и нижняя область страницы Models проверены на установленной версии 0.2.2-rc.1. Реализации серверной и браузерной частей не изменились; точная версия в engines обновляется только после этих проверок. Широкий диапазон будущих версий и исключение из проверки совместимости не используются. Прежний smoke-тест, запускавший браузерную ветку OAuth, заменён строго офлайн-тестом выбора и отмены. Установленный интерфейс, действительность токена и доступ реального аккаунта к моделям остаются отдельными проверками владельца; обновление не должно повторно авторизовывать пользователя или выполнять выход.

Это локальный сторонний плагин, а не официальная интеграция OpenAI или DeepSeek. Никогда не добавляйте в коммиты хранилища учётных данных, ответы OAuth, URL перенаправления, токены или личные скриншоты.

## Установка и удаление

Клонируйте репозиторий в постоянное место: установленный плагин ссылается на этот каталог. Используйте **CLI из комплекта Desktop, соответствующий версии приложения**, а не устаревшую команду `dsh` из npm. Проверено на macOS Desktop **0.2.2-rc.1**:

```sh
git clone https://github.com/rooty/dsh-chatgpt-oauth.git
cd dsh-chatgpt-oauth
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add "$PWD"
```

Установка npm-зависимостей и сборка не требуются: браузерный JavaScript уже подготовлен, а у пакета нет зависимостей времени выполнения. `private: true` предотвращает случайную публикацию в npm и не ограничивает доступ к этому репозиторию GitHub.

Команда изменяет только профиль Desktop. Полностью завершите приложение через **Cmd+Q** и откройте его снова, чтобы загрузилась серверная часть плагина. Установка не должна изменять `app.asar` или отключать проверку подписи кода. Для удаления:

```sh
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop remove @local/dsh-chatgpt-oauth
```

Исключение из проверки совместимости не используется. После будущего обновления DSH плагин с закреплённой версией может перестать загружаться, пока встроенные контракты авторизации и слотов не будут проверены заново.

## Известные ограничения

- Совместимость закреплена за DSH **0.2.2-rc.1**; другие версии не проверены.
- Если в момент открытия карточки на другой странице уже выполняется вход, кнопки могут остаться отключёнными после его завершения. Повторно откройте Settings → Models или обновите страницу, чтобы перезагрузить статус.
- Автоматические тесты не подтверждают права по подписке или фактический доступ к моделям. После входа проверьте их успешным запросом к модели.
