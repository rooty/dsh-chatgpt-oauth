# Локальний ChatGPT OAuth для DeepSeek Harness

[English](README.md) | [Русский](README.ru.md) | [Українська](README.uk.md)

Мінімальний плагін під контролем користувача для **DSH 0.2.2-rc.1** (версія плагіна **0.1.1**). Додає картку входу до ChatGPT внизу сторінки **Settings → Models** і викликає встановлений механізм авторизації `llm-pi-ai/openai-codex`. Плагін не реалізує власний протокол OAuth, не запускає Codex CLI, не замінює провайдера DSH і не налаштовує пошук чи генерування зображень.

## Використання

1. Відкрийте Settings → Models і знайдіть картку **ChatGPT / Codex sign-in**.
2. Натисніть **Sign in with ChatGPT** / **Войти через ChatGPT**.
3. Виберіть **Browser login (default)** і натисніть **Continue**, а потім завершіть вхід на відкритій сторінці OpenAI. Якщо браузер не відкрився, скористайтеся посиланням **Open ChatGPT sign-in** у картці. Вбудований механізм також пропонує **Device code login (headless)**; якщо виберете цей спосіб, дотримуйтеся вказівок на екрані.
4. Якщо DSH запитає код підтвердження або URL переспрямування, введіть його лише в картці, а не в чаті.
5. Коли DSH повідомить про збереження даних входу, за потреби налаштуйте розташованого вище провайдера `openai-codex`. Завантажте список доступних моделей і натисніть Apply. Плагін навмисно зберігає наявні списки моделей, адреси API та перевизначення налаштувань провайдера.

Індикатор збережених даних означає лише наявність запису в сховищі облікових даних DSH. Він не підтверджує права за передплатою, чинність токена, доступність сервісу чи успішне виконання запиту до моделі. Фактичний вхід і доступ до моделей потрібно перевіряти інтерактивно разом із власником облікового запису.

Дія **Sign out of DSH** після підтвердження видаляє лише запис `llm-pi-ai/openai-codex` зі сховища DSH. Вона не відкликає сеанс облікового запису в OpenAI, не виконує вихід із ChatGPT і не змінює облікові дані Codex CLI.

## Безпека та життєвий цикл

- Точні POST-маршрути реєструються через наявний транспорт Connection `/api` у DSH, який допускає автентифіковані підключення власника (owner Peers). Плагін не запускає додатковий API-сервер; вбудований браузерний OAuth може тимчасово відкрити локальний обробник зворотного виклику на порту 1455.
- Кожен маршрут додатково вимагає JSON Content-Type і заголовок `X-DSH-Codex-OAuth: 1`. Заголовок Origin вебзапиту, якщо він присутній, має відповідати фактичному Host, включно з портом. Автентифікований міст Desktop `dsh-app://app` навмисно видаляє Origin, тому відсутність Origin допускається лише всередині наявного транспорту Connection з автентифікацією власника. Тіло запиту обмежене 16 КіБ і проходить перевірку.
- Одночасно може виконуватися лише одна спроба входу. Її випадковий ідентифікатор зберігається в картці, яка ініціювала вхід, і не публікується в спільному стані; інші сторінки отримують лише логічну ознаку поточної спроби.
- Запити на введення, посилання та коди підтвердження зберігаються лише тимчасово. Вбудований механізм DSH записує й оновлює токени у власному сховищі облікових даних; плагін не читає та не повертає їхні значення.
- Картка містить посилання лише на обмежений набір офіційних HTTPS-хостів OpenAI. Вона не записує відповіді під час входу до журналів і не зберігає їх у постійному сховищі браузера.
- Скасування та демонтування компонента припиняють спробу. Термін дії спроби спливає через десять хвилин, її кінцевого стану — через одну хвилину. Звільнення серверної частини плагіна скасовує роботу й очищає таймери.
- Плагін постачається з готовим браузерним JavaScript, сумісним із завантажувачем. Після встановлення оновіть наявний інтерфейс; спостерігач розробки чи окремий вебсервер не потрібні.

## Перевірка

Запустіть `npm run check` із цього каталогу з Node.js 22 або новішим. Усі 32 детерміновані тести використовують синтетичні облікові дані та імітацію вбудованої авторизації; вони не звертаються до OpenAI й не витрачають квоту. Клієнтські тести використовують ізольовані тестові реалізації хуків, а не справжній браузер чи DOM.

На macOS запустіть `npm run test:native`: команда використовує середовище Electron, що постачається з Desktop. Перевіряються **реально встановлені** AuthorizationService, адаптер pi-ai і транспорт Connection. Тест авторизації скасовує вхід на етапі вибору браузерного входу або коду пристрою **без відповіді на запит вибору**: браузер, обробник зворотного виклику, запит коду пристрою та обмін токенами не запускаються. Тест Connection перевіряє допуск власника для запитів формату Desktop і вебзапитів із відповідним Origin, а також відхилення ворожих Host/Origin, анонімних запитів і запитів не від власника. Автентифікація синтетична, сокети не створюються. Мережевий fetch вимкнено в обох тестах. Справжнє сховище облікових даних не створюється й не перевіряється.

Для версії 0.1.1 вбудовані контракти й нижню область сторінки Models перевірено на встановленій версії 0.2.2-rc.1. Реалізації серверної та браузерної частин не змінилися; точна версія в engines оновлюється лише після цих перевірок. Широкий діапазон майбутніх версій і виняток із перевірки сумісності не використовуються. Попередній smoke-тест, який запускав браузерну гілку OAuth, замінено суто офлайн-тестом вибору й скасування. Встановлений інтерфейс, чинність токена та доступ справжнього облікового запису до моделей залишаються окремими перевірками власника; оновлення не повинно повторно авторизувати користувача чи виконувати вихід.

Це локальний сторонній плагін, а не офіційна інтеграція OpenAI або DeepSeek. Ніколи не додавайте до комітів сховища облікових даних, відповіді OAuth, URL переспрямування, токени чи особисті знімки екрана.

## Встановлення та видалення

Клонуйте репозиторій у постійне місце: встановлений плагін посилається на цей каталог. Використовуйте **CLI з комплекту Desktop, що відповідає версії застосунку**, а не застарілу команду `dsh` із npm. Перевірено на macOS Desktop **0.2.2-rc.1**:

```sh
git clone https://github.com/rooty/dsh-chatgpt-oauth.git
cd dsh-chatgpt-oauth
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop add "$PWD"
```

Встановлення npm-залежностей і збирання не потрібні: браузерний JavaScript уже підготовлено, а пакет не має залежностей часу виконання. `private: true` запобігає випадковій публікації в npm і не обмежує доступ до цього репозиторію GitHub.

Команда змінює лише профіль Desktop. Повністю завершіть застосунок через **Cmd+Q** і відкрийте його знову, щоб завантажилася серверна частина плагіна. Встановлення не повинно змінювати `app.asar` або вимикати перевірку підпису коду. Для видалення:

```sh
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" plugin --profile desktop remove @local/dsh-chatgpt-oauth
```

Виняток із перевірки сумісності не використовується. Після майбутнього оновлення DSH плагін із закріпленою версією може перестати завантажуватися, доки вбудовані контракти авторизації та слотів не буде перевірено знову.

## Відомі обмеження

- Сумісність закріплено за DSH **0.2.2-rc.1**; інші версії не перевірено.
- Якщо на момент відкриття картки на іншій сторінці вже виконується вхід, кнопки можуть залишитися вимкненими після його завершення. Повторно відкрийте Settings → Models або оновіть сторінку, щоб перезавантажити статус.
- Автоматичні тести не підтверджують права за передплатою чи фактичний доступ до моделей. Після входу перевірте їх успішним запитом до моделі.
